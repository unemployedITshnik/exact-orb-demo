# exact-orb

Deterministic astrological calculations with explicit separation between
calculation and interpretation layers.

## Точки без единого определения

### Селена

Селена / Белая Луна не является физическим телом и не входит в Swiss
Ephemeris как единый канонический объект. В проекте она рассчитывается через
заменяемые стратегии.

Доступные методики:

- `mean_perigee`: точка, противоположная среднему апогею Луны
  (`swe.MEAN_APOG + 180°`). Это средний перигей лунной орбиты, период около
  8.85 года.
- `true_perigee`: точка, противоположная оскулирующему апогею Луны
  (`swe.OSCU_APOG + 180°`). Это истинный перигей лунной орбиты с колебаниями
  относительно среднего положения.

Для карты `1985-09-01 20:45 UTC, Москва` фактические значения:

- `mean_perigee`: `220.201551°`, Скорпион 10°12'06"
- `true_perigee`: `225.502570°`, Скорпион 15°30'09"
- geocult reference: примерно `225.374167°`, Скорпион 15°22'27"

`true_perigee` близок к внешнему источнику и выбран в проектном конфиге
`pyproject.toml`. При отсутствии настройки базовое значение в коде остаётся
`mean_perigee`, чтобы явно сохранять исходную традицию среднего перигея.
