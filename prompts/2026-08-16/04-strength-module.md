ЧАСТЬ 4. ИТОГОВАЯ ПОМЕТКА СИЛЫ
═══════════════════════════════════════════════════════════

total = essential + accidental (+ модификаторы)

Категории (пороги в конфиг):
  strong      total >= 5
  moderate    0 <= total < 5
  weak        total < 0

ВАЖНО: пометка «слабая» НЕ означает «плохая». Она означает,
что планета действует непрямо, через другие точки, требует
усилия для проявления. Зафиксируй это в docstring и в выводе —
иначе интерпретирующий слой будет читать это как оценку.

Выводи обе составляющие отдельно, а не только сумму: планета
может быть эссенциально слабой и акцидентально сильной, и это
принципиально разные ситуации.

ЧАСТЬ 5. ДИСПОЗИТОРСКИЕ ЦЕПОЧКИ
═══════════════════════════════════════════════════════════

Диспозитор планеты — управитель знака, в котором она стоит.
Цепочка строится, пока не замкнётся.

ОБРАБОТКА ЦИКЛОВ — ОБЯЗАТЕЛЬНА
Цепочка всегда конечна и всегда завершается циклом длины 1
(планета в своей обители) или длины 2+ (взаимная рецепция
или более длинный цикл). Алгоритм: идти по ссылкам, запоминая
посещённые узлы; при повторе — зафиксировать цикл и остановиться.
Без этого будет бесконечный цикл.

ЭТАЛОН — диспозиторы карты 1985
  Солнце (Дева)      → Меркурий
  Луна (Овен)        → Марс
  Меркурий (Лев)     → Солнце
  Венера (Лев)       → Солнце
  Марс (Лев)         → Солнце
  Юпитер (Водолей)   → Сатурн
  Сатурн (Скорпион)  → Марс
  Уран (Стрелец)     → Юпитер
  Нептун (Козерог)   → Сатурн
  Плутон (Скорпион)  → Марс

Ожидаемый результат: ВСЯ карта сходится в цикл длины 2 —
взаимная рецепция Солнце ↔ Меркурий (Солнце в Деве под
управлением Меркурия, Меркурий во Льве под управлением Солнца).

Примеры цепочек:
  Луна → Марс → Солнце → Меркурий → [Солнце] цикл
  Уран → Юпитер → Сатурн → Марс → Солнце → Меркурий → цикл
  Плутон → Марс → Солнце → Меркурий → цикл

Выведи: цепочку для каждой планеты, длину до цикла, состав
финального цикла, и отдельно — список взаимных рецепций.
Взаимная рецепция (цикл длины 2) — самостоятельный
интерпретационный показатель, помечай отдельно.

Выводи абсолютные суммы, доли в процентах и пометку

  воздух: Юпитер(Водолей), MC(Водолей)
  вода:   Сатурн, Плутон(Скорпион), ASC(Рак)

  кардинальный: Луна(Овен), Нептун(Козерог), ASC(Рак)

Дополнительно: полусферы (север/юг по горизонту, восток/запад
по меридиану) и распределение по типам домов.

ЧАСТЬ 7. ФАЗА ЛУНЫ ПРИ РОЖДЕНИИ
═══════════════════════════════════════════════════════════

Элонгация = (долгота Луны − долгота Солнца) mod 360.
Восемь фаз по 45° (система Рудьяра):

  0–45     новолуние
  45–90    растущий серп
  90–135   первая четверть
  135–180  растущая выпуклая
  180–225  полнолуние
  225–270  распространяющаяся
  270–315  последняя четверть
  315–360  бальзамическая

ЭТАЛОН
  Солнце 159.340833, Луна 7.665
  элонгация = 208.324°
  фаза = ПОЛНОЛУНИЕ (пятая), 28.3° после точной оппозиции

Выведи: элонгацию, название фазы, номер, и расстояние до
границ соседних фаз.

ЧАСТЬ 8. ОСОБЫЕ ГРАДУСЫ
═══════════════════════════════════════════════════════════

Флаги в структуре данных, не только в рендере CLI.

  is_zero_degree      градус < 1° в знаке
  is_anaretic         градус >= 29° в знаке
  is_critical         по традиции лунных стоянок:
                        кардинальные знаки: 0, 13, 26
                        фиксированные:      8, 9, 21, 22
                        мутабельные:        4, 17
                      допуск ±1°, в конфиг

ЭТАЛОН
  Нептун 0°52 Козерог     → zero_degree + critical (кардинал 0°)
  Юпитер 8°41 Водолей     → critical (фикс. 8–9°)
  Меркурий 22°05 Лев      → critical (фикс. 21–22°)
  Сатурн 22°36 Скорпион   → critical (фикс. 21–22°)
  куспид 5 дома 29°44 Дева  → anaretic
  куспид 11 дома 29°44 Рыбы → anaretic

Помечай традицию явно: критические градусы — не общепринятый
инструмент, часть школ их не использует. Флаг конфигурируемый.

ЧАСТЬ 9. ИНТЕРЦЕПЦИИ В ДАННЫХ
═══════════════════════════════════════════════════════════

Убедись, что интерцепции присутствуют в JSON как отдельная
структура, а не только в текстовом выводе:

  intercepted: [{sign, house}]
  near_intercepted: [{sign, house, remaining_arc, threshold}]

ЭТАЛОН
  intercepted:       Весы в 5 / Овен в 11, Стрелец в 6 / Близнецы в 12
  near_intercepted:  Дева в 4 / Рыбы в 10, остаток 0°15'03"

Инвариант: количество интерцептированных знаков всегда чётное,
они образуют оппозиционные пары. Property-based тест.

═══════════════════════════════════════════════════════════
ЧАСТЬ 10. ТЕСТЫ
═══════════════════════════════════════════════════════════

- Достоинства: все десять планет, обе системы (traditional
  и modern дают разный результат для Плутона).
- Акцидентальная сила: типы домов, ретроградность.
- Диспозиторы: цепочки совпадают с эталоном, цикл найден,
  взаимная рецепция Солнце–Меркурий распознана.
- ЦИКЛЫ: синтетический кейс с циклом длины 3+ не приводит
  к зацикливанию. Обязательный тест.
- Планета в своей обители даёт цикл длины 1.
- Баланс: суммы и доли, доминирование фиксированного креста.
- Фаза Луны: элонгация 208.324, фаза «полнолуние».
- Особые градусы: все шесть случаев эталона.
- Интерцепции: чётность, оппозиционность пар.

Property-based:
- сумма весов по стихиям равна сумме по крестам
- элонгация всегда в [0, 360), фаза всегда одна из восьми
- цепочка диспозиторов всегда конечна для любого набора позиций

Запусти и покажи фактический вывод.
