# Configuration module

Реализуй модуль конфигураций exact-orb.

═══════════════════════════════════════════════════════════
ЧАСТЬ 1. МОДУЛЬ
═══════════════════════════════════════════════════════════

Это МОДУЛЬ, не tool. Строится поверх аспектного слоя, результат
входит в get_natal() наравне с аспектами.

  src/exact_orb/configurations/
  ├── types.py       Configuration, ConfigurationType
  ├── finder.py      find_configurations()
  └── patterns/      по файлу на семейство фигур

ЯДРО

  find_configurations(
      aspects: list[Aspect],
      config: ConfigurationConfig,
  ) -> list[Configuration]

Вход — уже найденные аспекты, не позиции. Модуль не пересчитывает
геометрию, а собирает фигуры из готовых рёбер. Это принципиально:
конфигурация существует только если существуют все её аспекты
в пределах орбисов, заданных для аспектов.

Модель Configuration:
  type          тип фигуры
  points        участники в канонической роли (apex, base, ...)
  aspects       рёбра, из которых собрана
  max_orb       худший орбис среди рёбер — мера качества фигуры
  chart         принадлежность карте

═══════════════════════════════════════════════════════════
ЧАСТЬ 2. ФИГУРЫ
═══════════════════════════════════════════════════════════

Реализуй в порядке возрастания сложности.

ТАУ-КВАДРАТ (t_square)
  A ☍ B, обе □ C. Вершина (apex) — C.
  Роли: apex, base_1, base_2.

ЙОД / ПЕРСТ СУДЬБЫ (yod)
  A ⚻ B, A ⚻ C, B ⚹ C. Вершина — A.
  Роли: apex, base_1, base_2.

БИСЕКСТИЛЬ (bisextile)
  A ⚹ B, B ⚹ C или A ⚹ B, B △ C — фигура из двух рёбер с общей
  точкой. ВНИМАНИЕ: в источнике geocult бисекстиль записан как
  тройка с центральной точкой посередине названия, например
  «Луна — Юпитер — Хирон» означает, что Юпитер центральный.
  Проверь фактическую геометрию (см. эталон) и задокументируй
  своё определение.

БОЛЬШОЙ КРЕСТ (grand_cross)
  Две оппозиции, скрещённые четырьмя квадратами.
  Проверь стихию: кардинальный / фиксированный / мутабельный.

БОЛЬШОЙ ТРИГОН (grand_trine)
  Три тригона попарно. Стихия обязательна в выводе.

ТРАПЕЦИЯ (trapeze)
  Четырёхточечная фигура. Определение в источнике неоднозначно —
  выведи из эталона фактическую геометрию и задокументируй.

ДЕДУПЛИКАЦИЯ — ГЛАВНАЯ ЛОВУШКА
Одна и та же фигура не должна находиться несколько раз при разном
порядке перебора вершин. Канонизируй: сортируй участников по
фиксированному правилу (например по долготе), сравнивай множествами.
Явный тест обязателен.

ВЛОЖЕННОСТЬ
Большой крест содержит два тау-квадрата. Реши и задокументируй:
выводятся ли вложенные фигуры отдельно. По умолчанию — нет,
выводится старшая, вложенные помечаются в поле contains.

ВАЖНОЕ НАБЛЮДЕНИЕ
Источник использует ОЧЕНЬ широкие орбисы для конфигураций —
до 6.8°. При max_orb 3° большинство фигур не соберётся.
Значит порог орбиса для конфигураций конфигурируется ОТДЕЛЬНО
от порога аспектов: configuration_max_orb, по умолчанию 7°.
Иначе эталон не воспроизведётся.

Добавь в вывод поле max_orb каждой фигуры — оно показывает,
насколько фигура тесная. Йод Солнце–Луна–Юпитер с max_orb 1.68
и йод Луна–Солнце–Плутон с max_orb 6.68 — это фигуры совершенно
разной силы, и вывод должен позволять их различить.

ЧАСТЬ 4. ТЕСТЫ
═══════════════════════════════════════════════════════════

- Полнота: все восемь фигур эталона найдены, лишних нет.
  Сравнение множествами участников, не по порядку.
- Вершины определены верно: Солнце в первом йоде, Луна во втором,
  Юпитер в двух тау-квадратах.
- max_orb каждой фигуры совпадает с эталоном (0.01°).
- Дедупликация: перестановка порядка точек на входе не меняет
  количество найденных фигур.
- Порог: при configuration_max_orb = 2.0 остаются только
  тау-квадраты с Юпитером; йод Луна–Солнце–Плутон исчезает.
- Пустой вход даёт пустой список, не падение.

Property-based:
- количество фигур не растёт при уменьшении порога орбиса
- каждая найденная фигура содержит ровно столько рёбер, сколько
  требует её определение
- все рёбра фигуры присутствуют во входном списке аспектов

Запусти и покажи фактический вывод.
Если какая-то фигура эталона не находится — сначала объясни
причину геометрически, потом правь.
