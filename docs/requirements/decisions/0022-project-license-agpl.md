# ADR-0022. Лицензия проекта: AGPL-3.0 на публичной фазе

Дата: 2026-09-03.
Статус: принято.

## Контекст

Репозиторий публичный и используется как открытая витрина работы. Файла
`LICENSE` в нём до сих пор не было, то есть по умолчанию действовало «все
права защищены»: формально код нельзя было использовать никому, что
противоречило самому смыслу публикации.

Проект зависит от `pysweph` — производной работы от Swiss Ephemeris.
Swiss Ephemeris распространяется по двойной лицензии: AGPL-3.0 либо платная
Professional License. Текст лицензии Astrodienst называет момент выбора
явно:

> the choice must be made before the software developer distributes software
> containing parts of Swiss Ephemeris to others, and before any public
> service using the developed software is activated

Сегодня ни распространения, ни сетевого сервиса нет, поэтому нарушения нет.
Но решение не было зафиксировано нигде, а сроки его принятия определяются
не нами: блок F дорожной карты поднимает публичный стенд.

Отдельный фактор — сохранение возможности выпустить закрытую коммерческую
версию. Она есть, пока автор единственный правообладатель, и исчезает при
первом принятом чужом вкладе.

## Решение

На публичной фазе проект распространяется под **GNU Affero General Public
License version 3**. Полный текст — файл `LICENSE` в корне репозитория.

Pull request'ы с кодом не принимаются; политика зафиксирована в
`CONTRIBUTING.md`. Предложения принимаются через issues и реализуются
автором.

Приобретение Professional License откладывается до момента, когда
понадобится закрытый или монетизируемый сервис.

## Альтернативы

**Swiss Ephemeris Professional License, 700 CHF разово, unlimited.**
Снимает AGPL полностью и разрешает закрытый код на любой стадии. Отвергнута
на текущем этапе: расход до подтверждения продукта, при том что сегодня
обязательства не наступили. Остаётся основным кандидатом на момент
монетизации.

**Замена расчётного движка.** `libephemeris` (Apache-2.0) поверх Skyfield и
JPL DE440 позиционируется как drop-in замена `pyswisseph`; связка
Skyfield (MIT) + файлы JPL DE — как более низкоуровневый вариант. Оба
снимают лицензионный вопрос бесплатно и навсегда. Отвергнуты на текущем
этапе: замена движка обесценивает `tests/golden/natal_1985_human.txt` и
фикстуры, откалиброванные по Swiss Ephemeris, а `libephemeris` вышел
в текущем виде в мае 2026 и не проверен на составе точек, который использует
проект — Хирон, оскулирующий апогей, полный набор `ascmc`. Проверка
пригодности возможна как отдельный эксперимент; менять фундамент, пока это
не требуется, — риск без выигрыша. Граница для такой замены уже существует:
`swiss_backend.py` — единственная точка входа `swisseph`, закреплённая
тестом `test_swisseph_enters_the_process_through_one_module`.

## Последствия

- Весь проект целиком обязан оставаться под AGPL-3.0 или совместимой
  лицензией. Это относится и к рецептам интерпретации блока H, то есть к
  основной ценности продукта, а не только к расчётному ядру.
- AGPL §13: при активации публичного сервиса на нём обязана быть заметная
  ссылка на полный исходный код, доступный бесплатно любому пользователю
  сервиса. Это входит в объём блока F наравне с маскированием логов.
- AGPL не запрещает брать деньги за доступ к сервису (§4), но запрещает
  скрывать исходный код от его пользователей. Платный AGPL-сервис возможен;
  закрытый — нет.
- Перелицензирование будущих версий остаётся возможным, пока автор —
  единственный правообладатель. Отсюда запрет на приём pull request'ов.
- Версии, уже выпущенные под AGPL, остаются под AGPL для тех, кто их
  получил. Закрывается будущее, не прошлое.
- Файлы эфемерид `ephe/*.se1` могут храниться в репозитории: право их
  распространять следует из того, что проект под AGPL.
- Отдельное требование лицензии Swiss Ephemeris действует при любом выборе:
  имена авторов и Astrodienst не используются для продвижения проекта без
  письменного разрешения, copyright notices сохраняются в копиях.
- Решение подлежит пересмотру **до** активации закрытого или
  монетизируемого сервиса. Смена лицензии — новый ADR, а не правка этого.
