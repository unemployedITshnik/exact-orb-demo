# ADR-0019. Распознавание данных рождения в свободном тексте отложено

Дата: 2026-08-25. Статус: принято.

## Контекст

Свободный текст может содержать данные рождения:

```
«построй карту мужу, 3 марта 1988, Киров»
```

Поддержка этого требует извлечения даты и места из текста, резолва места
с обработкой неоднозначности в диалоге, отдельной идентификации субъекта
и решения, становится ли новая карта базовой. Каждый пункт тянет собственные
краевые случаи.

## Решение

**В MVP свободный текст не является источником данных рождения.** Единственный
источник — `SessionProfile`, заполняемый формой.

Из этого следует:

* `IntentService` не извлекает `birth_slots`;
* `BirthDataResolver` в свободном пути не вызывается;
* дополнительные request-scoped карты не считаются;
* изменение данных рождения через чат отсутствует (ADR-0014).

**Упомянутая дата не игнорируется молча.** Молчаливый ответ про сохранённую
карту — худший исход: пользователь получит осмысленный текст и решит, что
система его поняла. Rule-based **детектор** даты и места в свободном тексте —
без резолва — возвращает явный отказ через существующий тип:

```
InputRequired { issues: [{
    field: "subject", code: UNSUPPORTED,
    constraints: "изменение данных рождения — через форму"
}] }
```

Распознавать — нет, замечать — да.

## Альтернативы

Поддержать NL-ввод данных рождения в MVP — отвергнуто: объём работы несоразмерен
demo. Игнорировать упомянутые даты — отвергнуто: тихая подмена субъекта хуже
отказа. Блокировать любое сообщение с числами — отвергнуто как грубое.

## Последствия

- Свободная ветка сжимается до
  `InputGuard → Admission → IntentService → ContractValidator → PolicyService`.
- Неоднозначность места порождается только эндпоинтом подсказок, поэтому
  проблема неидемпотентного повторного извлечения (ADR-0007) в MVP не возникает.
- Затрагивает ADR-0005, 0007, 0011, 0014, 0015 — все в сторону упрощения.
- На схеме компонентов отложенная ветка изображается пунктиром с меткой
  `future`, а не удаляется: иначе она будет дорисована заново без знания
  о принятом решении.
