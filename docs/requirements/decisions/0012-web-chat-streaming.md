# ADR-0012. Bootstrap и chart/chat page; streaming применяется к интерпретации

Дата: 2026-08-21. Ревизия: 2026-08-25 — UI больше не «только чат»; уточняет
ADR-0006; перечень классов операций перенесён в ADR-0015.
Статус: принято.

## Контекст

Исходный ADR описывал интерфейс как веб-чат со свободным вводом и делал
оркестратор источником SSE для всего. Теперь поток начинается до чата: сначала
данные и карта, затем взаимодействие. Детерминированный расчёт и многосекундная
генерация имеют разные транспортные требования.

## Решение

**Start page.** `birth_date` (required), `birth_time` (optional), `birth_city`
(required, выбор из подсказок → `place_id`). Submit:
`API → BirthDataResolver → calculation → Session → Chart page`. При неизвестном
времени строится космограмма (ADR-0008).

**Chart page.** Визуализация, базовые данные, явные контролы их изменения
и переключения вида (ADR-0014), preset-действия, свободный чат при наличии
capability (ADR-0015).

**Транспорт.**

* операции без LLM — обычный request/response;
* операции с генерацией — SSE с событиями `status`, `input_required`, `token`,
  `done`, `error`.

Событие `clarification` переименовано в `input_required` вслед за ADR-0007.

**Уточнение ADR-0006.** Endpoint построения карты вызывает application service
расчёта напрямую, минуя оркестратор.

**Отказы обязаны быть представимы.** Событие `error` порождается при
недоступности движка или провайдера, исчерпании квоты и дневного потолка;
сценарии описаны в `docs/sequence_diagrams/general_e2e/`. Компонент, порождающий
`error`, должен быть назван явно, иначе событие остаётся декларацией.

## Альтернативы

Единый `/chat` на всё — отвергнуто: разные контракты, стоимость и security
semantics. SSE для детерминированного построения — допустимо, не требуется.
Фоновая задача + polling — отложено.

## Последствия

- Пользователь видит карту до любого обращения к LLM.
- Ошибка после начала стрима передаётся событием `error`.
- `complete_stream()` остаётся обязательным методом LLM Gateway.
- Детерминированный путь требует собственного таймаута и целевого p95: поиск
  станций транзита — самая долгая операция в системе.
