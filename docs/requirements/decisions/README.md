# Записи архитектурных решений (ADR)

Формат: контекст — решение — альтернативы — последствия.

Решение действует, пока не появится запись, явно его отменяющая. Номер
не переиспользуется; отменённая целиком запись помечается «Заменено ADR-NNNN».

Запись может быть ревизована на месте, если решение то же, а меняются его
границы, формулировки или следствия. Ревизия несёт строку
`Ревизия: <дата> — <что изменилось>` и явно называет отменяемые следствия
прошлой редакции. Меняется само решение — выпускается новый номер.

## Замечание об именах файлов

Слаги двух записей отстали от их содержания после ревизии 2026-08-25:
`0005-resolve-in-intent-layer.md` — резолвер больше не принадлежит intent-слою;
`0007-clarification-service.md` — `ClarificationService` отменён.
Файлы намеренно не переименованы, чтобы не рвать ссылки и историю; при следующей
крупной правке слаги стоит привести к содержанию.

## Ревизии 2026-08-27

Разбор блока резолва (`component_responsibilities/exact-orb_birth_data_resolution.md`)
потребовал трёх ревизий на месте:

* **0005** — отменены `place_substituted`, `place_input_text` и порог 0.5°:
  флаг неоткуда взять, порог невычислим. Подстановка ближайшего города
  остаётся текстом в форме.
* **0007** — `AMBIGUOUS` отсутствует на build-пути только для места;
  для времени возникает штатно. Ошибки схемы уходят наружу тем же контрактом.
* **0008** — подставленный полдень не порождает вопросов пользователю
  даже при попадании в аномалию часового пояса.

## Ревизии 2026-09-05

Реализация процессного session persistence уточнила границы уже принятых
lifecycle-решений:

* **0009** — `touch` остаётся единственным read-and-renew; фасетные
  `get`/`read` read-only, а успешные CAS/append/clear являются
  write-and-renew. Append продлевает state и dialog одним deadline, clear
  продлевает state без изменения content/version и удаляет dialog.
* **0024** — SQLite append/clear обязаны выполнять то же изменение одной
  `BEGIN IMMEDIATE … COMMIT`; parent state является единственным источником
  liveness, а persisted dialog deadline используется согласованным lifecycle
  и reaper.
