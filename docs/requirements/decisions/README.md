# Записи архитектурных решений (ADR)

Формат: контекст — решение — альтернативы — последствия.

Решение действует, пока не появится запись, явно его отменяющая. Номер
не переиспользуется; отменённая целиком запись помечается «Заменено ADR-NNNN».

Запись может быть ревизована на месте, если решение то же, а меняются его
границы, формулировки или следствия. Ревизия несёт строку
`Ревизия: <дата> — <что изменилось>` и явно называет отменяемые следствия
прошлой редакции. Меняется само решение — выпускается новый номер.
