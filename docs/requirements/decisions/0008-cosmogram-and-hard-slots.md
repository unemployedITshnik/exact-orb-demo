# ADR-0008. Космограмма при неизвестном времени; место и дата — жёсткие слоты

Дата: 2026-08-21. Ревизия: 2026-08-25 — приведено к коду: `chart_kind` —
параметр движка; в список исключаемых блоков добавлен `strength`; **отменено**
утверждение «космограмма — подтип сценария, а не движка».
Статус: принято. Отменяет решение о подстановке полудня.

## Контекст

Без точного времени недостоверны дома, Ascendant, MC и производное: дом меняется
раз в четыре минуты. Подстановка полудня отменена ранее — такие дома произвольны,
но выглядят настоящими. После появления формы неизвестное время стало штатным
состоянием structured input.

## Решение

```
дата + место + время → natal chart
дата + место         → cosmogram
```

`birth_date` и `birth_place` обязательны. `birth_time` не обязателен; пустое поле
— явное `time_unknown = true`, вопрос не задаётся.

**Космограмма — уровень движка.** `calculate_natal()` принимает обязательный
`chart_kind: Literal["natal", "cosmogram"]`, валидирует согласованность
с `include` и проставляет `NatalChart.chart_kind`.

Рассчитываются `positions`, `aspects`, `configurations`. Не рассчитываются
`houses`, `angles`, `house_rulers`, `interceptions` и **`strength`** — последний
в коде требует `houses`.

Полдень — техническая опорная точка для долгот, не должен создавать видимость
известного времени ни в одном поле результата.

**Предупреждения** добавляются при смене знака Луны или знака либо директности
быстрого объекта в пределах суток. Обобщённая формулировка «существенно
неоднозначно» не используется: критерий должен быть проверяем тестом.

Рецепт `cosmogram.*` запрещает утверждения о домах, Ascendant, MC и управителях
домов.

## Альтернативы

Полдень + полный чарт — отменено. Требовать время обязательным — отвергнуто.
Спрашивать время в чате после пустого поля — отвергнуто.

## Последствия

- Вид карты определяется полем `chart_kind`, а не отсутствием домов (И-8).
- UI обязан визуально различать натал и космограмму.
- `warnings` доходят до `InterpretationService` (И-7).
- **Связка «космограмма + транзит» не работает.** В `charts/transit.py`
  блокируют два места: `if natal.cusps is None: raise ValueError("natal chart
  must include houses for transit house placement")` и в `_natal_points`
  `if natal.bodies is None or natal.angles is None: raise ValueError(...)` —
  вторая срабатывает на `angles`, входящих в блок `houses`. Договорённость:
  считать транзитные аспекты к точкам космограммы с акцентом на медленные
  планеты, для чего нужен путь без углов. Следствие для UI — в ADR-0016.
  Это единственный оставшийся предметный пробел, и он затрагивает штатный
  пользовательский сценарий.
