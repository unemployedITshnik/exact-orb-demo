# ADR-0003. Сценарий = один промпт = один вызов LLM

Дата: 2026-08-21. Статус: принято.

## Контекст

Запрос может касаться нескольких техник сразу («расскажи про натал и транзиты
на сегодня»). Возникает развилка: делать по вызову модели на тему и склеивать
ответы, или собрать один составной промпт.

## Решение

Единица планирования — **сценарий** из конечного каталога. Инвариант: один сценарий
порождает один `PromptBundle` и один вызов модели, сколько бы инструментов внутри
ни отработало.

При нескольких темах в сценарии `PromptBuilder` берёт рецепт каждой темы в сжатом
варианте и собирает из них один промпт. Режим (`full` / `compact`) объявлен в
определении сценария, а не выводится из количества отработавших инструментов.

Количество фокусов внутри одной темы на режим не влияет: два фокуса — это более
богатый набор фактов для одного рецепта, а не две темы.

## Альтернативы

N вызовов модели с последующей склейкой. Отвергнуто: двойная стоимость и задержка,
плюс склейка двух самостоятельных текстов в связный ответ — отдельная нетривиальная
задача.

## Последствия

- `PromptBuilder` не умеет и не должен уметь склеивать несколько бандлов.
- Orchestrator не мержит несколько `LLMResponse`.
- Рецепты заводятся парами «полный / сжатый» на тему, а не под каждую комбинацию тем.
- Комбинация тем, которой нет в каталоге, требует явного решения (см. открытые вопросы).
