# ADR-0011. Intent Extractor применяется только к natural-language входу

Дата: 2026-08-21. Ревизия: 2026-08-25 — structured bootstrap и preset выведены
из-под Extractor; в MVP Extractor не извлекает данные рождения (ADR-0019).
Статус: принято.

## Контекст

Первая версия проектировалась как чистый чат, поэтому даже данные рождения
предполагалось получать через Extractor. Новая UI-модель использует два
интерфейса, и одинаковый pipeline им не нужен.

## Решение

`Intent Extractor` остаётся портом с адаптерами `RuleBasedExtractor`,
`LocalLLMExtractor`, `RemoteLLMExtractor`, но вызывается только там, где вход
действительно является естественным языком.

```
Start Form  → BirthDataInput → BirthDataResolver     Extractor не вызывается
Preset      → {topic, focus, active_view}            Extractor не вызывается
Free-form   → InputGuard → IntentService → …         Extractor вызывается
```

Свободный текст доступен только по подписке (ADR-0015), поэтому в MVP Extractor
не вызывается вовсе.

**Extractor не извлекает данные рождения.** Его результат
`UnderstandingResult { contract_fields, interpretation_query }` — тема, фокус
и вопрос; `birth_slots` относятся к отложенной функции (ADR-0019). Единственным
источником данных рождения остаётся `SessionProfile`. Отдельно работает детектор
даты и топонима, дающий `InputRequired` с кодом `UNSUPPORTED`.

Rule-based — первая и единственная реализация. Переход к schema-constrained
локальной модели возможен позже, но требует учесть цену из ADR-0007
(идемпотентность повторного извлечения). LLM-профиль «extraction» остаётся
отдельным от «interpretation».

## Альтернативы

Прогонять форму через Extractor — отвергнуто: лишний вероятностный шаг перед
детерминированным резолвером. Только форма — отвергнуто: диалог часть продукта.
Только natural language — отвергнуто: данные рождения структурны, а ошибки в них
искажают расчёт.

## Последствия

- Форма и чат не конкурируют.
- Первое построение карты не зависит ни от Extractor, ни от LLM.
- Rule-based extractor развивается независимо от стартовой страницы.
- `IntentService` возвращает один составной результат; разветвление выполняет
  handler, не сам сервис.
