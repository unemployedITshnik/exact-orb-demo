# Участие в проекте

Спасибо за интерес к exact-orb. Проект открыт для чтения, изучения и
обсуждения.

## Что приветствуется

- **Issues.** Найденная ошибка, расхождение с астрологическим эталоном,
  непонятное поведение, вопрос по архитектуре — всё это ценно и всё это
  лучше всего оформляется отдельным issue.
- **Обсуждения.** Замечания по расчётным решениям, по составу орбисов,
  по методикам расчёта неоднозначных точек вроде Селены.
- **Воспроизводимые примеры.** Дата, время, место и то, что вы ожидали
  увидеть вместо полученного, — самый полезный вид сообщения об ошибке.

## Pull request'ы с кодом сейчас не принимаются

Это осознанное ограничение, и оно не про качество чужой работы.

Проект распространяется под AGPL-3.0 и одновременно готовится к
коммерческой версии с закрытым исходным кодом. Такой переход возможен
только пока автор остаётся единственным правообладателем: перелицензировать
можно свой собственный код, но не чужой вклад. Один принятый pull request
делает переход невозможным без письменного согласия его автора — а найти
человека спустя год может не получиться.

Поэтому изменения кода вносит только автор проекта. Если ваше предложение
описано в issue, оно будет рассмотрено и, если окажется верным, реализовано
с указанием, кто его предложил.

Правки опечаток в документации обсуждаются отдельно в issue.

## Если политика изменится

Открытие проекта для вкладов потребует Contributor License Agreement,
дающего право сублицензировать вклад. Это отдельное решение, и оно будет
зафиксировано новым ADR в `docs/requirements/decisions/`. До тех пор
действует правило выше.
